Go gRPC client, under pressure

Read the contract. Reuse the connection. Bound every call. Classify every error.

Read this first

service Catalog {
  rpc GetBook(GetBookRequest) returns (Book);
}

The generator gives you a constructor similar to catalogpb.NewCatalogClient(conn) and a method similar to GetBook(ctx, request). Do not edit generated files.

The ordinary unary call

conn, err := grpc.NewClient(target,
    grpc.WithTransportCredentials(credentials.NewTLS(tlsConfig)),
)
if err != nil { return fmt.Errorf("create gRPC client: %w", err) }
defer conn.Close()

client := catalogpb.NewCatalogClient(conn)
ctx, cancel := context.WithTimeout(parent, 800*time.Millisecond)
defer cancel()

book, err := client.GetBook(ctx, &catalogpb.GetBookRequest{Id: id})
if err != nil {
    switch status.Code(err) {
    case codes.NotFound:
        // Map to the caller's domain result.
    case codes.DeadlineExceeded, codes.Unavailable:
        // Apply the service's approved retry or fallback policy.
    default:
        // Preserve the error, method, and safe request identifiers in logs.
    }
}

grpc.NewClient creates a virtual client connection and does no I/O itself. An RPC causes connection work as needed. Create it once per long-lived component, not once per request. Use the repository's credential and lifecycle pattern. API reference

Failure triage

What you seeFirst questionNext move
Compile errorIs the generated package/import current?Find the repo's generation command. Never patch generated Go.
UnauthenticatedWhich credentials or outgoing metadata does this service require?Copy the established client pattern, then verify key names and TLS.
DeadlineExceededDid our time budget expire, or did the server need longer?Check method latency and budget. Do not blindly increase it.
UnavailableCould the endpoint, TLS, DNS, proxy, or server be down?Inspect transport logs and service health. Retry only if the operation is safe.
NotFoundDoes absence belong in the normal domain result?Map it deliberately, rather than treating every non-OK status alike.

Metadata

md := metadata.Pairs("x-request-id", requestID)
ctx = metadata.NewOutgoingContext(ctx, md)
reply, err := client.GetBook(ctx, req)

Metadata is request context, not a replacement for fields that define the business request. Use exact keys and auth helpers already established by your service.
